# 专注计时（focus-timer）

小米 17 Pro 自用的小计时器：**设定时长 → 到点只响一声 → 继续默默计时 → 你手动停止才结束**。

## 它只做这些

- 多个项目，每个项目可设默认时长、提示音（叮 / 钟 / 钵 / 木鱼 / 磬 / 哔 / 自定义 / 关闭）、颜色、正面或负面。
- 点开始 → 后台计时（通知栏显示）；到点响**一声**（走闹钟通道，静音/勿扰也会响），**不停止**，继续计时。
- 手动停止才结束并落库；跨零点整笔记在**起始日**。
- 暂停 / 继续：暂停时时间定格、取消到点闹钟；继续时按剩余时间重排（2×2 小部件、通知栏、App 内均可操作）。
- 统计：项目内按周 / 月 / 年看合计、日均、次数、柱状分布和明细；另有**总统计**（累计打卡天数、累计时长、平均每天）、连续打卡天数、本周与上周对比。
- 负面项目可设**单日上限 / 单周上限**，超过弹一次提醒。
- 导出 JSON（全量备份）/ CSV（明细表），可导入还原。
- 「关于」页可看当前版本号与逐版本更新日志。

## 桌面小部件（两种，面板里直接选）

| 尺寸 | 样子 | 交互 |
|---|---|---|
| **2×1** | 一行：时长 + 开始胶囊；**计时中只变成「停止」一个胶囊**（暂停不在此，去 App 内或通知栏） | 只有胶囊按钮有功能，**点时长/项目名等空白处＝直接打开 App** |
| **2×2** | 圆标 + 项目名 + 计划时长 + 大数字 + 胶囊 | 同上 |

- 放置时先选项目与「点击时用多少分钟」（上次 App 设的 / 项目默认 / 自己定），长按可「编辑」重选。
- 颜色跟随项目色；背景跟随系统**深色模式**。
- 绑定的项目被删除后，点一下会提示重新选择项目。

## 权限（就这几个，没有别的）

| 权限 | 干什么用 |
|---|---|
| `POST_NOTIFICATIONS` | 通知栏显示正在计时、越界提醒 |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` | 后台持续计时 |
| `USE_EXACT_ALARM` | 到点**准点**响（系统里显示为"闹钟和提醒"） |
| `WAKE_LOCK` | 只在到点响那一声的两三秒内持有（不亮屏），否则锁屏下可能不响 |

**没有 `INTERNET`**（物理上不能联网）、**没有定位**、**没有存储读写**（导出导入走系统文件选择器）、没有开机自启、没有悬浮窗。

## 耗电

- **不计时**：服务停止即退出进程，无常驻循环、无周期闹钟、无轮询；小部件的系统定时刷新（`updatePeriodMillis`）已设为 `0`，空闲时零唤醒。
- **计时中·息屏**：不持唤醒锁，只 30 秒刷新一次通知，约 0.2–0.5%/小时。
- **计时中·亮屏**：小部件与通知的秒数每秒刷新（看得见才刷），约 +1%~2%/小时（屏幕本身占大头）。
- **到点响铃**：`setAlarmClock` 精确唤醒一次 + 20 秒部分唤醒锁，播完释放。

计时靠「起始时刻 + 系统时钟」相减，不靠 CPU 数秒，所以**即使进程被系统杀掉，时长依然算得准**——只有"到点响那一声"需要进程能被唤醒。

## 怎么拿到 APK

推送到 `main` 后自动跑 GitHub Actions：
仓库页 → **Actions** → 最新一次 `build-apk` → 页面底部 **Artifacts** → 下载 `focus-timer-apk` → 解压得到
`focus-timer-v<版本>-c<versionCode>-debug.apk` → 传手机安装（允许"安装未知来源应用"）。

### 签名

仓库根目录的 `keystore.p12` 是**固定签名**，CI 每次都用它签，所以**可以覆盖升级，不用卸载旧版**。
（这是自用 debug 签名，与任何账号凭据无关；换签名文件会导致必须卸载一次。）

## 装好后建议设的地方（MIUI / HyperOS）

1. 设置 → 应用 → 专注计时 → 省电策略 → **无限制**（避免后台被冻结，导致小部件/通知停更）
2. 通知权限保持允许；如需锁屏也能看到计时，见下一节

不需要开"自启动"（App 没有开机自启功能）。

## 小米 / HyperOS 让锁屏也显示计时（实测有效）

设置 → 通知与控制中心 → 应用通知 → 专注计时 → 通知类别 → **计时中** → **锁定屏幕** → 选「**显示通知及其内容**」。

只打开应用级的「锁屏通知」还不够，必须在这个**渠道**里把锁定屏幕设成"显示通知及其内容"，锁屏上才会出现项目名和实时时长。

App 内「自检 / 备份」页顶部有**通知自检**：能看到通知总开关、渠道重要性，可一键打开系统设置、发/清测试通知。

## 已知边界

- 手机重启后，历史上已保存的记录不会丢；但**正在跑的那一次计时不会自动续上**（不申请开机自启权限，符合"不要额外权限"的要求）。
- 到点提示音走**闹钟音量**，请确认闹钟音量不为 0；勿扰模式下系统需允许闹钟（默认允许）。
- 到点**不会自动亮屏**（明确不需要），只有声音提示。
- 计时随窗口小部件不受支持（小米桌面对 `Chronometer` 不支持运行时改字号/颜色，已改用普通文本 + 服务刷新）。
