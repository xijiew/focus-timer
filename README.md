# 专注计时（focus-timer）

**到点只响一声，然后继续。**

> 别的番茄钟打断你，它不打断。

专注被打断的那一刻，你失去的不是 25 分钟，是你刚刚进去的那个状态。

市面上的番茄钟几乎都在做同一件事：到点就把你拦一下——全屏弹窗、连响三遍、必须点"确认"。可深度专注不按每 25 分钟一格走。很多时候你正游到深处，被那一声拽回岸边，再想进去，又要重新付一次入场的代价。

所以我们换了个做法。

## 一声就够，然后它闭嘴

到点，响一声。**就一声。**

然后它安静地继续计时，直到你自己按下停止。

- 那一声是提醒：*你到了预定的时长*
- 不停，是尊重：*你还可以继续*
- 停止才结束，所以记录里存下的，是你**真实的专注时长**，不是你计划的时长

于是统计页上的数字，从"我打算专注多少"变成"我**真的**投入了多少"——这两者之间的差距，才是值得盯着看的东西。

## 静音、勿扰，也逃不掉这一声

走的是系统闹钟通道。静音、勿扰、锁屏深度休眠，这一声都会到。就响一下，不吵第二遍。

## 多个项目，看得见自己在变好

打坐、写作、读书、健身，各自一个项目，各自一个颜色。

- 按**周、月、年**看时长分布与柱状趋势
- **连续打卡天数** —— 让你舍不得断
- **本周 vs 上周**对比，涨了还是退了一目了然
- **累计打卡天数、累计时长、平均每天**，看得见的总量
- 负面项目（刷手机、熬夜）能设上限，超了提醒你一次

看得见的进步，才是能坚持的进步。

## 桌面上点一下就开始

2×1 和 2×2 两种小部件，放着显示项目名和时长，点按钮就开跑，**根本不用打开 App**。跟随系统深色模式，颜色跟着项目走。

## 没有联网权限，一条都没有

- **没有 `INTERNET` 权限** —— 它物理上连不上网。不是"承诺不上传"，是**没有能力上传**
- 不读位置、不读写手机存储、不开机自启、没有悬浮窗
- 没有广告、没有推荐、没有社交、没有升级弹窗

## 省电到你会忘记它在运行

不计时的时候，它不常驻、不定时唤醒、不轮询，CPU 一次都不会被它叫醒。计时中屏幕一暗，它就自动降低刷新频率。到点响那两三秒，是它唯一一次唤醒。

**一天下来，你几乎找不到它的耗电记录。**

## 它不是给所有人的

- 如果你需要"必须休息"的强制番茄钟 —— 它不是
- 如果你想要社群、排行榜、打卡分享 —— 它没有

**它适合这样的人**：用番茄钟却总被打断的；打坐、阅读、写作时不想被铃声切碎的；想知道自己一年到底专注了多少小时的；讨厌一个计时器却要联网要权限的人。

> 它的全部野心，就是在正确的时间响一声，然后闭嘴。

# 技术说明

**设定时长 → 到点只响一声 → 继续默默计时 → 你手动停止才结束**。Android 10（API 29）及以上，用 Kotlin + Jetpack Compose 编写，不依赖任何第三方服务。

## 功能清单

- 多个项目，每个项目可设默认时长、提示音（叮 / 钟 / 钵 / 木鱼 / 磬 / 哔 / 自定义 / 关闭）、颜色、正面或负面。
- 点开始 → 后台计时（通知栏显示）；到点响**一声**（走闹钟通道，静音/勿扰也会响），**不停止**，继续计时。
- 手动停止才结束并落库；跨零点整笔记在**起始日**。
- 暂停 / 继续：暂停时时间定格、取消到点闹钟；继续时按剩余时间重排（2×2 小部件、通知栏、App 内均可操作）。
- 统计：项目内按周 / 月 / 年看合计、日均、次数、柱状分布和明细；另有**总统计**（累计打卡天数、累计时长、平均每天）、连续打卡天数、本周与上周对比。**日均＝该期间合计 ÷ 该期间实际有专注的天数**（不是拿 7／30／365 天当分母）。
- **周统计与年统计的柱状图，每根柱子上方直接标出当天／当月专注时长**（月份柱多，数字自动缩小一号）；**点柱子可筛选下方明细**——周/月点某一天只看那天，年点某个月只看那个月每天合计数（再点一次取消）。
- **防手误**：一次专注**不满 1 分 30 秒**直接不记录、不提示；**1 分 30 秒～3 分钟**内点停止会先问一句「提前放弃专注？本次专注不足 3 分钟，记录将不会被保存。」，可选取消（继续计时）或放弃（停止且不保存）；**不满 3 分钟的专注一律不保存**（小部件、通知栏没界面问，也按这条走）。
- 负面项目可设**单日上限 / 单周上限**，超过弹一次提醒。
- 导出 JSON（全量备份）/ CSV（明细表），可导入还原。
- 「关于」页可看当前版本号与逐版本更新日志。

## 桌面小部件（两种，面板里直接选）

| 尺寸 | 样子 | 交互 |
|---|---|---|
| **2×1** | **第一行项目名**，第二行：时长 + 开始胶囊；**计时中只变成「停止」一个胶囊**（暂停不在此，去 App 内或通知栏） | 只有胶囊按钮有功能，**点时长/项目名等空白处＝直接打开 App** |
| **2×2** | 圆标 + 项目名 + 计划时长 + 大数字 + 胶囊 | 同上 |

- 放置时先选项目与「点击时用多少分钟」（上次 App 设的 / 项目默认 / 自己定），长按可「编辑」重选。
- 颜色跟随项目色；背景跟随系统**深色模式**。
- 绑定的项目被删除后，点一下会提示重新选择项目。

## 权限（就这几个，没有别的）

| 权限 | 干什么用 |
|---|---|
| `POST_NOTIFICATIONS` | 通知栏显示正在计时、越界提醒 |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` | 后台持续计时 |
| `USE_EXACT_ALARM` | 到点**准点**响（系统里显示为"闹钟和提醒"） |
| `WAKE_LOCK` | 只在到点响那一声的两三秒内持有（不亮屏），否则锁屏下可能不响 |

**没有 `INTERNET`**（物理上不能联网）、**没有定位**、**没有存储读写**（导出导入走系统文件选择器）、没有开机自启、没有悬浮窗。

## 耗电

- **不计时**：服务停止即退出进程，无常驻循环、无周期闹钟、无轮询；小部件的系统定时刷新（`updatePeriodMillis`）已设为 `0`，空闲时零唤醒。
- **计时中·息屏**：不持唤醒锁，只 30 秒刷新一次通知，约 0.2–0.5%/小时。
- **计时中·亮屏**：小部件与通知的秒数每秒刷新（看得见才刷），约 +1%~2%/小时（屏幕本身占大头）。
- **到点响铃**：`setAlarmClock` 精确唤醒一次 + 20 秒部分唤醒锁，播完释放。

计时靠「起始时刻 + 系统时钟」相减，不靠 CPU 数秒，所以**即使进程被系统杀掉，时长依然算得准**——只有"到点响那一声"需要进程能被唤醒。

## 怎么拿到 APK

推送到 `main` 后自动跑 GitHub Actions：
仓库页 → **Actions** → 最新一次 `build-apk` → 页面底部 **Artifacts** → 下载 `focus-timer-apk` → 解压得到
`focus-timer-v<版本>-c<versionCode>-debug.apk` → 传手机安装（允许"安装未知来源应用"）。

### 签名

仓库根目录的 `keystore.p12` 是**固定签名**，CI 每次都用它签，所以**同一台手机上可以覆盖升级，不用卸载旧版**。

> ⚠️ 注意：这个签名文件与密码**公开在仓库里**，属于 debug 级别的自用签名，只用于免去反复卸载的麻烦，**不能当作安全边界**。如果你要用它正式发布，请换一把自己的 keystore，并在 `app/build.gradle.kts` 里替换配置。

## 装好后建议设的地方（MIUI / HyperOS）

1. 设置 → 应用 → 专注计时 → 省电策略 → **无限制**（避免后台被冻结，导致小部件/通知停更）
2. 通知权限保持允许；如需锁屏也能看到计时，见下一节

不需要开"自启动"（App 没有开机自启功能）。

## 小米 / HyperOS 让锁屏也显示计时（实测有效）

设置 → 通知与控制中心 → 应用通知 → 专注计时 → 通知类别 → **计时中** → **锁定屏幕** → 选「**显示通知及其内容**」。

只打开应用级的「锁屏通知」还不够，必须在这个**渠道**里把锁定屏幕设成"显示通知及其内容"，锁屏上才会出现项目名和实时时长。

App 内「自检 / 备份」页顶部有**通知自检**：能看到通知总开关、渠道重要性，可一键打开系统设置、发/清测试通知。

## 已知边界

- 手机重启后，历史上已保存的记录不会丢；但**正在跑的那一次计时不会自动续上**（不申请开机自启权限，符合"不要额外权限"的要求）。
- 到点提示音走**闹钟音量**，请确认闹钟音量不为 0；勿扰模式下系统需允许闹钟（默认允许）。
- 到点**不会自动亮屏**（明确不需要），只有声音提示。
- 小部件的数字不用系统 `Chronometer`：MIUI / HyperOS 桌面不支持运行时改字号与颜色，已改成普通文本 + 前台服务刷新。
- 开机自启、联网、定位、存储读写权限一个都没有；因此也不存在「重启后自动续上正在跑的计时」这类功能。
